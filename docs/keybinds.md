# Keybindings

All bindings live in `dotfiles/bspwm/sxhkdrc`.

| Keys | Action |
|---|---|
| Super+Return | Alacritty |
| Super+Shift+Return | Alacritty floating |
| Super+Alt+Return | Alacritty fullscreen |
| Ctrl+Alt+T | Kitty |
| Alt+F1 / Super | rofi launcher |
| Alt+F2 | rofi runner |
| Super+B/M/N/R/S/T/W/X | bluetooth, music, network, asroot, screenshot, themes, windows, power menu |
| Super+Shift+F/W/E | Thunar, Firefox, Geany |
| Ctrl+Alt+V/R/H | vim, ranger, htop |
| Super+P | color picker |
| Ctrl+Alt+M | music menu |
| Ctrl+Alt+L | betterlockscreen |
| Print | screenshot now |
| Alt+Print / Shift+Print | screenshot in 5s / 10s |
| Ctrl+Print | active window |
| Super+Print | area |
| Super+Q | close window |
| Super+Shift+C | kill window |
| Ctrl+Shift+Q/R | quit / restart bspwm |
| Super+Escape | reload sxhkd |
| Super+1..8 | switch workspace (Shift sends window) |
| Ctrl+Alt+Left/Right | previous/next workspace |
| Super+Arrows | focus (Shift swaps) |
| Super+Alt+Arrows | resize |
| Super+H/V | split horizontal/vertical |
| Super+Ctrl+Q | cancel preselection |
| Super+L | toggle layout |
| Super+F | fullscreen |
| Super+Space | toggle floating |
| Super+Tab / Super+` | last window / last workspace |
| Alt+Tab | next window including floating |
